Create the admin password

This page turns your password into a one-way hash for Netlify. Everything happens in this browser: the password is never sent or saved anywhere.

Add these in Netlify → Site configuration → Environment variables. Then redeploy.

You can change ADMIN_USERNAME to any name you like. To change the password later, come back here, create a new hash and replace ADMIN_PASSWORD_HASH.
